Description:

libft is a custom C library developed as part of the 42 School curriculum. The goal of this project is to recreate several standard C library functions and develop a deeper understanding of how they work internally.
The library includes functions for string manipulation, character checking, memory management, and linked list operations. It also provides utility functions for writing characters, strings, and numbers to file descriptors.
By implementing these functions from scratch, the project strengthens fundamental C programming skills, including pointers, memory allocation, data structures, and error handling.
The resulting libft.a static library can be reused in future C projects, reducing the need to rewrite common utility functions.

Instruction:

To compile the library, run the following command in the project directory:

make

This generates the static library libft.a, which contains the compiled functions.

Available Commands:

make — Compiles the source files and creates libft.a.

make clean — Removes the object files (.o).

make fclean — Removes the object files and the compiled library (libft.a).

make re — Removes the previous build and recompiles the library.
